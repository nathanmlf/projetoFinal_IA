# StockSys - Sistema de Controle de Estoque com IA

![StockSys Banner](https://images.unsplash.com/photo-1586528116311-ad8dd3c8310d?ixlib=rb-4.0.3&auto=format&fit=crop&w=1200&q=80)

**StockSys** é um sistema moderno de gerenciamento de estoque desenvolvido para facilitar o controle de produtos, quantidades e valores. O diferencial do projeto é a integração com um **Chatbot de IA** (via n8n), permitindo que usuários consultem o estoque e tirem dúvidas através de uma interface de chat natural.

## ✨ Funcionalidades

- **📦 Gestão de Produtos**:
  - Cadastro completo com imagem, categoria, preço e quantidade.
  - Listagem visual com indicadores de nível de estoque (Baixo/Em Dia).
  - Busca em tempo real por nome ou categoria.
  - Exclusão de itens.
- **📊 Dashboard Rápido**:
  - Visualização imediata do total de produtos, itens em estoque e valor total acumulado.
- **🤖 Assistente Virtual (IA)**:
  - Chatbot integrado capaz de responder perguntas sobre o estoque.
  - Processamento de linguagem natural via n8n.
- **🎨 Interface Moderna**:
  - Design responsivo e limpo focado em UX.
  - Feedback visual (toasts) para ações do usuário.

## 🛠️ Tecnologias Utilizadas

- **Frontend**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Estilização**: [Tailwind CSS](https://tailwindcss.com/) + [Lucide React](https://lucide.dev/) (Ícones)
- **Backend / Banco de Dados**: [Supabase](https://supabase.com/) (PostgreSQL + Storage)
- **Automação / IA**: [n8n](https://n8n.io/) (Workflows de Chat e Webhooks)

## 🚀 Como Rodar o Projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado.
- Conta no [Supabase](https://supabase.com/) com um projeto criado.
- Instância do [n8n](https://n8n.io/) (local ou cloud) configurada.

### 1. Configuração do Ambiente

1.  Clone o repositório:
    ```bash
    git clone https://github.com/seu-usuario/estoque-app.git
    cd estoque-app
    ```

2.  Instale as dependências:
    ```bash
    npm install
    ```

3.  Crie um arquivo `.env` na raiz do projeto baseado no exemplo abaixo:

    ```env
    VITE_SUPABASE_URL=sua_url_supabase
    VITE_SUPABASE_ANON_KEY=sua_key_anonima_supabase
    VITE_N8N_WEBHOOK_URL=url_do_webhook_de_eventos_n8n
    VITE_N8N_CHAT_WEBHOOK_URL=url_do_webhook_de_chat_n8n
    ```

### 2. Configuração do Banco de Dados (Supabase)

Crie uma tabela chamada `products` no seu Supabase com a seguinte estrutura:

```sql
create table products (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  category text not null,
  price numeric not null,
  quantity numeric not null,
  description text,
  image_url text
);
```

*Lembre-se de configurar as Policies (RLS) para permitir leitura e escrita, e criar um Bucket chamado `product-images` para o upload de imagens.*

### 3. Executando a Aplicação

1.  **Frontend**:
    ```bash
    npm run dev
    ```
    O app estará disponível em `http://localhost:5173`.

2.  **Backend (n8n Tunnel)**:
    Se estiver rodando o n8n localmente e precisar expô-lo para o frontend:
    ```bash
    npx n8n start --tunnel
    ```
    *Nota: Atualize as URLs no `.env` sempre que o túnel for reiniciado.*
